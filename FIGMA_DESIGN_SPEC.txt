1. VISUAL TOKEN MATRIX & DESIGN SYSTEM
--------------------------------------------------------------------------------

COLOR PALETTE (DUAL MODES)

Mode A: Arrakis Twin Sun (Default / Light Palette)
  - Background Base (bg-primary):       #1A1206 (Deep desert charcoal/brown)
  - Surface / Panels (surface):         #3D2B14 (Tempered sandstone)
  - Surface Hover (surface-hover):      #4A351A
  - Primary Accent (accent-primary):    #D4A843 (Spice gold)
  - Secondary Accent (accent-secondary):#E8C068 (Sunlight sand)
  - Text Primary (text-primary):        #F5E6C8 (Parchment white)
  - Text Secondary (text-secondary):    #C4A882 (Muted desert earth)
  - Borders / Dividers (border):        #4A351A (1px solid)
  - Accent Glow (glow):                 0px 0px 20px rgba(212, 168, 67, 0.3)

Mode B: Giedi Prime Infrared (Dark / High-Contrast Palette)
  - Background Base (bg-primary):       #000000 (Monochrome pure black)
  - Surface / Panels (surface):         #141414 (Carbon industrial plate)
  - Surface Hover (surface-hover):      #1F1F1F
  - Primary Accent (accent-primary):    #FFFFFF (Clinical stark white)
  - Secondary Accent (accent-secondary):#FF1A1A (Infrared targeting red)
  - Text Primary (text-primary):        #E0E0E0 (Clean grey)
  - Text Secondary (text-secondary):    #808080 (Muted machine steel)
  - Borders / Dividers (border):        #333333 (1px solid)
  - Accent Glow (glow):                 0px 0px 20px rgba(255, 26, 26, 0.25)

TYPOGRAPHY RULES
  - Headings / Display: Sans-Serif Bold / Black (Inter or Space Grotesk). All-caps, tracking +0.05em to +0.1em.
  - Data, Stats, Badges, Code: Monospace (JetBrains Mono). Uppercase, tracking +0.08em.
  - Body Text: Clean Sans-Serif (Inter), line-height 1.6, regular weight (400).

SHAPE & SURFACE TREATMENT
  - Corner Radii: Strict small radii. 4px on buttons, inputs, and cards. No pill shapes except active status badges.
  - Borders: 1px hairline borders on all panels and cards using assigned border token.
  - Glassmorphism: backdrop-filter: blur(12px) on navigation bar, sticky CTA bars, and dialog overlays.

CURSOR ASSETS (DESKTOP ONLY)
  - Default State: Code Geass ceremonial sword vector graphic (sharp geometric blade, 24x24px, 4px hotspot offset).
  - Interactive / Pointer State: Same sword angled 15 degrees with accent gold/red outline glow.
  - Mobile / Touch: Native OS cursor only. Custom cursor asset excluded on mobile artboards.


2. GLOBAL SHELL LAYOUT
--------------------------------------------------------------------------------

TOP NAVIGATION BAR
  - Position: Fixed top, full width, 72px height, 1px bottom border, glassmorphism background.
  - Left Anchor: Fest logo mark (TECHSRIJAN) + sub-brand tag (REQUIEM).
  - Center Links: EVENTS, ACCOMMODATION, SCHEDULE, SPONSORS (uppercase monospace, active indicator is a 2px bottom accent line).
  - Right Controls:
      * Theme toggle switch (Arrakis Sun icon <-> Giedi Prime Crosshair icon).
      * ENTER SYSTEM primary button (links to Login / Dashboard).
  - Mobile View (< 768px): Center links hidden; replaced by 2-line geometric hamburger icon opening a full-screen drawer.

FOOTER
  - Layout: 4-column structured grid (desktop) collapsing to single column (mobile).
  - Content Blocks:
      * Col 1: TechSrijan crest, MMMUT Gorakhpur affiliation text, copyright notice.
      * Col 2: Navigation link cluster.
      * Col 3: Legal & Support (Privacy Policy, Refund Rules, Code of Conduct).
      * Col 4: Direct coordinator contacts and social media icon cluster (X, Instagram, LinkedIn, Discord).

FLAGSHIP EVENTS CAROUSEL

4-POINT STAT BAR

  - Cell 3: TIMELINE -> 36 HOURS SPRINT.

CONTENT COLUMNS (70/30 SPLIT)

  - Right Column (30% Sticky Panel):
      * Registration Card: Price highlight, registration deadline countdown.
      * Registration Action Button: REGISTER NOW.
      * Rulebook Download: File icon + DOWNLOAD PDF RULES link.

REGISTRATION MODAL / DRAWER FLOW
  - Trigger: Click on REGISTER NOW.

  - Branch B (Team Event):

      * If Create: Input field for Team Name -> Generates display of 8-character invite code.
      * If Join: Input field for Enter 8-Digit Invite Code.

7. SCREEN 5: STUDENT DASHBOARD (/dashboard/student)
--------------------------------------------------------------------------------

IMPERIUM PASS COMPONENT (PRIMARY ASSET)
  - Visual Style: High-tech digital boarding pass card. Cut-out notches on left/right edges.
  - Left Section (65%):
      * TechSrijan logo + OFFICIAL ADMIT CARD.
      * Student Name, Affiliated College Name, Roll/Student ID Number.
      * Registered Events pill tags.
  - Right Section (35%):
      * Large high-contrast square QR Code frame.
      * Alphanumeric Pass Code printed under QR: TS26-XXXX-XXXX.
  - Actions Strip Below Pass: DOWNLOAD PASS (PNG) button + PRINT button.

REGISTERED EVENTS TABLE
  - Columns: EVENT, TYPE (Solo/Team), ROLE (Leader/Member), STATUS, ACTIONS.
  - Status Badges:
      * CONFIRMED: Green border, green text, green dot icon.
      * PENDING REVIEW: Amber border, amber text, alert triangle icon.
      * FAILED: Red border, red text.
  - Pending State Interaction: Amber alert box under table with button: CONTACT DESK WITH RECEIPT.

TEAM ROSTER SECTION
  - Layout: Card list for every team the user belongs to.
  - Content: Team Name, Event name, list of team members with Leader crown icon, copyable INVITE CODE field with COPY icon button.

--------------------------------------------------------------------------------

KPI METRIC CARDS
  - Layout: 4 horizontal metric tiles across top row.

  - Metric 2: Gross Revenue Collected (₹X,XX,XXX).
  - Metric 3: Pending Manual Reviews (Highlighted in Amber if > 0).

MASTER REGISTRATIONS DATA TABLE
  - Top Bar: Search input (Name, Email, Payment ID) + Filter Tabs (ALL, CONFIRMED, NEEDS REVIEW, FAILED) + EXPORT CSV button.
  - Columns:
      * Checkbox (Select row).
      * Participant Name & Email.
      * Event Name.
      * Amount Paid.
      * Razorpay Order ID & Payment ID (Monospace text).
      * Status Badge.
      * Action Menu (... dropdown): Mark Approved, View Receipt, Revoke Pass.
  - Pagination Footer: Row count indicator (Showing 1-25 of 1,240) + Previous / Next page buttons.


9. SYSTEM STATES & OVERLAYS
--------------------------------------------------------------------------------

  - Loading State: Dark surface card with animated skeleton shimmering gradient (rgba(255,255,255,0.05)).
  - Empty State: Geometric dashed border box with central terminal icon, title NO DIRECTIVES FOUND, and action link RESET FILTERS.
  - Toast Notifications: Monospace terminal notification anchored bottom-right.
      * Success: Green accent left border + checkmark.
      * Error / Warning: Red or Amber accent left border + alert glyph.
  - Auth Modal: Split visual modal:
      * Left side (Desktop): Dune sand landscape illustration with imperial crest.
      * Right side: Clean login form containing "Continue with Google" single-click button.
